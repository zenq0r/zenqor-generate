# Sistem Quotation & Invoice - ZENQOR TECHNOLOGIES

Sistem Quotation & Invoice moden berasaskan web yang dibina menggunakan HTML5, Tailwind CSS, dan Vue.js. Sedia untuk dihoskan secara percuma di **GitHub** dan **Vercel**.

---

## 🚀 Cara Publish ke GitHub & Vercel (1 Minit Saja)

### Langkah 1: Muat Naik ke GitHub
1. Buka [GitHub.com](https://github.com) dan log masuk ke akaun anda.
2. Klik butang **"+"** di sudut kanan atas -> **New repository**.
3. Berikan nama repository (Contoh: `zenqor-invoice-system`) -> Pilih **Public** atau **Private** -> Klik **Create repository**.
4. Di halaman repository, klik **uploading an existing file**.
5. Tarik dan lepas (drag & drop) fail `index.html`, `vercel.json`, `.gitignore`, dan `README.md` ke dalam halaman tersebut.
6. Klik **Commit changes**.

---

### Langkah 2: Publish secara PERCUMA di Vercel
1. Buka [Vercel.com](https://vercel.com) dan log masuk menggunakan akaun **GitHub** anda.
2. Klik butang **"Add New..."** -> Pilih **Project**.
3. Anda akan nampak repository `zenqor-invoice-system` yang baru dimuat naik tadi -> Klik **Import**.
4. Biarkan semua tetapan asal (Framework Preset: **Other**) -> Klik **Deploy**.
5. Tunggu 10 saat dan sistem anda akan terus *live* di internet dengan link HTTPS percuma!

---

## ✨ Ciri-Ciri Utama
- **Auto-Numbering:** Penomboran Quotation & Invoice secara automatik.
- **Validiti Dinamik:** Mengira baki hari validiti Quotation secara automatik mengikut tarikh.
- **Pengurusan Rekod:** Simpan dan hapus rekod dokumen lepas terus di dalam *Local Storage* pelayar web.
- **Cetak / PDF A4:** Rekabentuk korporat dengan margin A4 tepat tanpa gangguan menu antaramuka.
